# 8051 Experiments

This directory contains the 8051 portion of the Fundamentals of IoT laboratory work. The projects use AT89S52-compatible Keil C51 projects; pin mappings and timing values are documented per experiment.

## Experiments

| CAT | Documentation | Scope |
|---|---|---|
| CAT1 | [CAT1](CAT1/README.md) | Introductory experiment folder; no implementation files are currently tracked here. |
| CAT2 | [CAT2](CAT2/README.md) | AT89S52 toolchain bring-up and software LED blinking. |
| CAT3 | [CAT3](CAT3/README.md) | Four LED patterns selected by a debounced switch. |
| CAT4 | [CAT4](CAT4/README.md) | Keypad scanning, seven-segment display, and LED actions. |
| CAT5 | [CAT5](CAT5/CAT5A/README.md) | Timer interrupt, PWM, waveform, and stepper-motor exercises. |
| CAT6 | [CAT6A](CAT6/CAT6A/README.md) / [CAT6B](CAT6/CAT6B/README.md) | UART transmission and character echo. |
| CAT7 | [CAT7A](CAT7/CAT7A/README.md) / [CAT7B](CAT7/CAT7B/README.md) / [CAT7C](CAT7/CAT7C/README.md) | LCD and keypad-controlled display exercises. |

`Objects/README.md` files are retained build-directory placeholders and do not contain experiment documentation.
